# Unique SKU Generation

## Feature Name
Unique SKU Generation

## Short Description
The system assigns a unique Stock Keeping Unit (SKU) code to each store item. The SKU helps identify each item quickly and prevents confusion between similar products.

## Purpose
The purpose is to give every item a unique identification code that makes products easier to identify, search, organize, and track.

## Main Functions/Activities
- Generate a unique SKU for each item.
- Prevent duplicate SKU codes.
- Link each SKU to the correct product.
- Allow users to search for an item using its SKU.
- Update SKU information when necessary.
