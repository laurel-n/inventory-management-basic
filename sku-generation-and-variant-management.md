# Feature: Automated SKU Generation and Variant Management

## Short Description
This feature automatically creates a unique Stock Keeping Unit (SKU) code for every new product and its variants such as size, color, and material, using a standardized naming pattern.

## Purpose
To eliminate manual errors and duplication when creating product codes, and to ensure every item variant can be uniquely identified across the entire inventory system.

## Main Functions / Activities
- Auto-generates SKU code based on category, brand, and attributes (e.g., SHRT-NIKE-BLK-M-001).
- Validates SKU uniqueness to prevent duplicate codes.
- Manages product variants under one parent product.
- Allows searching and filtering of items using SKU.
- Links SKU to barcode for scanning.
