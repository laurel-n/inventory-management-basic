SKU Creation and Assignment

Short Description

SKU (Stock Keeping Unit) Creation and Assignment is the process of giving each store item a unique identification code. The code helps the store easily identify and manage different products.

Purpose

The purpose is to make it easy to identify, search, track, and manage items in the store.

Main Functions/Activities

- Create a unique SKU for each item.
- Assign the SKU to the correct product.
- Record the product name and description.
- Record important product details such as size, type, or brand.
- Search for an item using its SKU.
- Prevent duplicate identification of items.
